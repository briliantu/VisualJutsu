# Hand-seal diagrams

These twelve SVG files are original, simplified pose illustrations made for Sealcraft. They are designed as learning aids and are not exact anatomical diagrams or copied anime/manga panels.

| File | Seal | Main pose cue |
| --- | --- | --- |
| `dragon.svg` | Dragon | Hands upright together; left thumb over right |
| `tiger.svg` | Tiger | Joined hands upright; thumbs point up |
| `dog.svg` | Dog | Left hand flat over right fist |
| `rat.svg` | Rat | Joined upright hands; left thumb outside |
| `ram.svg` | Ram | Hands joined vertically; left thumb over the top |
| `horse.svg` | Horse | Index fingers meet to make a triangle |
| `monkey.svg` | Monkey | Hands horizontal; thumbs rest across the little fingers |
| `bird.svg` | Bird | Fingertips meet at a peaked angle |
| `ox.svg` | Ox | Right hand horizontal across the upright left hand |
| `serpent.svg` | Serpent | Hands joined; left thumb visible on the outside |
| `hare.svg` | Hare | Fingers curl gently while little fingers stay apart |
| `boar.svg` | Boar | Hands interlaced with wrists relaxed |

The pose names and short cues are based on the hand-seal references supplied for this project. Consult the in-app **Learn** guide for the complete sequence of instructions and camera tips for each pose.
